## 🚀 Quick Start

### View the Website Locally

**Option 1: Simple File Open**
```bash
cd construction-site
# Then open index.html in your web browser
```

**Option 2: With Live Server (Recommended)**
```bash
cd construction-site
python3 -m http.server 8000
# Then visit http://localhost:8000
```

**Option 3: VS Code Live Server**
- Open `construction-site/index.html` in VS Code
- Right-click and select "Open with Live Server"

## 🎨 Quick Customization

### 1. Update Contact Information
Edit `construction-site/index.html` and search for:
- `(555) 123-4567` - Replace with real phone
- `info@montyconstruction.com` - Replace with real email
- `123 Construction Way` - Replace with real address

### 2. Change Colors
Edit `construction-site/css/style.css` at the top:
```css
:root {
    --primary-color: #ff6b35;      /* Change this */
    --secondary-color: #f7931e;    /* And this */
}
```

### 3. Add Your Photos
Add images to `construction-site/images/`:
- `hero-bg.jpg` (1920x1080px) - Hero background
- `about-placeholder.jpg` (800x600px) - About section
- `project-placeholder-1.jpg` through `4.jpg` (800x600px) - Projects

## 🌐 Deploy Your Website

### GitHub Pages (Free)
1. Push to GitHub
2. Settings → Pages → Select branch
3. Your site: `https://yourusername.github.io/repo-name/construction-site/`

### Netlify (Free + HTTPS)
1. Sign up at netlify.com
2. Drag and drop the `construction-site` folder
3. Get instant live URL with HTTPS

### Traditional Hosting
1. Upload `construction-site` folder via FTP
2. Point domain to the folder
3. Done!
