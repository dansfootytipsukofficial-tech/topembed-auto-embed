## Image Guidelines

### Quality
- Use high-resolution images (at least 1200px width for hero)
- Compress images for web (use tools like TinyPNG or ImageOptim)
- Maintain aspect ratios to prevent distortion

### Format
- Use JPEG for photographs
- Use PNG for images with transparency
- Consider WebP format for better compression (with JPEG fallback)

### Optimization Tips
1. Resize images to exact dimensions needed
2. Compress to reduce file size (aim for under 200KB per image)
3. Use appropriate quality settings (80-85% is usually sufficient)
4. Consider lazy loading for below-the-fold images

### Recommended Tools
- **Online**: TinyPNG, Squoosh.app, Compress JPEG
- **Desktop**: Adobe Photoshop, GIMP, ImageOptim (Mac)
- **CLI**: imagemagick, sharp (Node.js)

## Placeholder Generation

Until you have actual images, the website will display placeholder areas. To create quick placeholders:

### Using Placeholder Services (Temporary)
```html
<!-- Example placeholder URLs -->
<img src="https://via.placeholder.com/800x600/FF6B35/FFFFFF?text=Project+1">
<img src="https://via.placeholder.com/1920x1080/1a1a1a/FFFFFF?text=Hero+Background">
```

### Creating Solid Color Placeholders
You can create simple colored rectangles in any image editor:
1. Create new image with required dimensions
2. Fill with a solid color or gradient
3. Add text overlay with project name
4. Save as JPEG

## Best Practices

1. **Consistency**: Use similar lighting and style across project images
2. **Quality**: High-resolution, well-composed photographs
3. **Relevance**: Images should showcase actual work when possible
4. **Diversity**: Show variety of project types and scales
5. **Professional**: Avoid blurry, poorly lit, or amateur photos
